# ChiCha Gateway

Build a polished responsive landing page for ChiCha.

Use the attached/reference mockup as the visual direction, but create a cleaner production-ready long-scroll website. The site should be simple, role-based, and focused on account entrance. Do not overbuild it into a complex product map.

Brand:

Company name: ChiCha

Category: Web3 payment infrastructure for stablecoin payments

Font: Inter

Style: premium dark fintech, Web3-native but trustworthy, clean, modern, serious enough for merchants and partners, simple enough for regular users

Main colors:

Background: #090911

Dark section/card area: #343445

Primary purple: #905EE9

Primary mid: #6C44B7

Primary dark: #4A3078

Secondary cyan: #19CFD4

Secondary dark teal: #185766

Light text: #FFFFFF

Muted text: #838391

Light background option: #F1F1F7

Use purple-to-cyan gradients for primary buttons, highlights, icons, and subtle background glow.

Use rounded cards, soft borders, subtle shadows, and glassy dark panels.

Use the ChiCha logo from the uploaded/reference brand kit if available. If not available, create a placeholder logo area but do not invent a new logo direction.

Important website strategy:
This website should be a simple role-based entrance into the ChiCha ecosystem.

The page should help visitors quickly choose the right path:

Users

Merchants

Partners / Agents

Token / Ecosystem information

Token / Ecosystem should be visible but secondary. It should not visually dominate Users, Merchants, or Partners.

Build only one homepage for now. Subpages can be placeholder routes or anchor sections. Do not create a full multi-page website unless needed for navigation placeholders.

Top navigation:

Logo left: ChiCha

Nav links: Users, Merchants, Partners, Token, News

Right side: Login, Get Started button

Mobile design:

Fully responsive

Mobile header with logo and hamburger menu

Stack hero content cleanly

Role cards become vertical list cards

Users/Merchants sections stack vertically

Account entrances stack into compact cards

Use bottom navigation style only if helpful, with: Home, Users, Merchants, Partners, Token

Design details:

Keep the long-scroll desktop design clean and spacious.

Do not include a separate brand panel on the right side of the actual website. The right-side view in the reference mockup is only the mobile responsive preview.

Keep density lower than the reference mockup. Use whitespace and breathing room.

Use dark mode as the main theme.

Use purple/cyan gradients sparingly for CTA buttons, icon glows, and section highlights.

Make the page feel like payment infrastructure, not a crypto casino or token sale.

Compliance and wording guardrails:
Avoid:

Use:

Non-custodial wallet flows

Account entrance

Subject to policy

Official token information

Approved token access paths

Technical requirements:

Build in React/Next-style component structure if applicable.

Use reusable components: Header, Hero, RoleCard, FeatureSection, EntranceCard, Footer.

Make the code clean and easy to edit.

Use placeholder links for all CTAs.

Ensure desktop and mobile responsiveness.

Add smooth hover states to cards and buttons.

No unnecessary animation. Subtle glow and transitions only.

Do not add login functionality, wallet connection, backend, KYC flow, or payments integration yet. This is a front-end website mockup / landing page only.
