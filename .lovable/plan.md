# ChiCha landing page plan

## Build
- Replace the placeholder homepage with one polished, responsive long-scroll ChiCha landing page.
- Add reusable sections for the header, hero, role choices, user, merchant, partner, ecosystem, account entrances, and footer.
- Keep every action as a placeholder link; no login, wallet, payment, or backend behavior.

## Visual direction
- Apply the supplied Inter-based dark fintech palette through semantic design tokens.
- Use restrained purple-to-cyan accents, glassy panels, rounded cards, soft borders, and subtle interaction states.
- Use an existing uploaded ChiCha logo if available; otherwise show a neutral ChiCha wordmark placeholder.
- Create a simple premium payment-device visual with CSS and icons, without inventing a new logo.

## Responsive behavior
- Add a compact mobile menu and stack content cleanly on smaller screens.
- Keep role selection and account entrances highly scannable, with token information visually secondary.

## Validation
- Verify the page at desktop and mobile sizes, including navigation, content fit, and section layout.
- Add page-specific title and social metadata.
